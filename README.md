# Hi, I'm Zach Eritson

**Technical solutions specialist.** I build systems that solve real problems for individuals, businesses and organisations. I start with how people actually work, then build the software that makes that work easier, more reliable and easier to see.

## What I build

- **Management systems.** For example: a school management system covering admissions, boarding, transport, fees with M-Pesa payment matching, uniform and food stores, and timetabling for Kenyan CBC schools.
- **Commerce platforms.** Online shops with admin dashboards, bookings, customer accounts, Stripe and WhatsApp checkout, and generated PDF documents.
- **Publishing platforms.** Fast, content-driven sites built with MDX, multilingual support and search, plus custom WordPress themes.
- **Integrations** with the services businesses rely on: M-Pesa, Africa's Talking SMS, Stripe, Shopify and cloud storage.

## How I work

- **Problem first.** I learn how the people who will use a system work before choosing the technology.
- **Correct where it counts.** Money, stock and records get strict rules, audit trails and tests that prove them.
- **Built to be affordable.** I design for low running costs, so small organisations can keep their systems going.
- **Written down.** Decisions, trade-offs and hand-off notes are documented, so the next person can pick the work up.
